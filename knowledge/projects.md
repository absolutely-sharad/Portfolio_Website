# Detailed Projects Knowledge

## AI Job-Hunt Copilot
- Problem: Job seekers spend 40+ hours per week manually tailoring resumes and tracking hundreds of job openings.
- Solution: Autonomous agentic pipeline parsing candidate career history, matching jobs with vector embeddings, auto-generating ATS resumes, and crafting personalized outreach.
- Stack: Gemini 2.5 Flash, LangChain, FastAPI, PostgreSQL (pgvector), Next.js, Tailwind CSS.
- Outcome: Reduced application prep time by 75% and boosted interview callbacks by 2.4x across 120 beta users.
- Live Deployed: https://github.com/absolutely-sharad/Ai_Job-Hunt_Copilot#deploy-to-vercel
- GitHub Repository: https://github.com/absolutely-sharad/Ai_Job-Hunt_Copilot

## StudyOS
- Problem: Students struggle to synthesize dense lecture slides, textbooks, and audio notes into actionable study plans.
- Solution: All-in-one AI study platform converting materials into active recall flashcards, concept graphs, and spaced repetition schedules.
- Stack: React, TypeScript, Node.js, Express, Supabase, Gemini API, Pinecone.
- Outcome: Adopted by 850+ active university students with an 18% retention score gain.
- Live Deployed: https://github.com/absolutely-sharad/studyos
- GitHub Repository: https://github.com/absolutely-sharad/studyos

## Gemini Pro Chat App
- Problem: AI chat interfaces often suffer from hallucinated answers, laggy token streams, and lack workspace action execution.
- Solution: Real-time contextual chat interface with document grounding, multimodal support, and Server-Sent Events token streaming.
- Stack: React 19, Vite, @google/genai, TypeScript, Tailwind CSS, SSE.
- Outcome: Sub-150ms time-to-first-token with zero dropouts on 10,000+ character documents.
- Live Deployed: https://nextjs-ai-chatbot-pied-three-81.vercel.app
- GitHub Repository: https://github.com/absolutely-sharad/Google_Gemini-Pro_Chat_Application

## Enterprise Finance Tracker
- Problem: Freelancers and boutique agencies lose track of multi-currency invoice statuses, cash-flow forecasting, and recurring subscription drain.
- Solution: Encrypted personal and team finance ledger that imports multi-bank CSVs, auto-categorizes expenses via NLP, and provides predictive cash flow forecasting.
- Stack: Next.js, TypeScript, PostgreSQL, Prisma ORM, Docker, Chart.js.
- Outcome: Detected an average of $380/mo in redundant subscription leaks for 45 early agency clients.
- Live Deployed: https://financetracker-absolutely-sharad.netlify.app
- GitHub Repository: https://github.com/absolutely-sharad/Finance-Tracker-Application

## Village Run 3D (The Indian Runner)
- Problem: Mobile web 3D games often suffer from sluggish frame rates and large engine downloads on budget devices.
- Solution: Procedural 3D endless runner built directly in WebGL and Three.js with custom collision math, dynamic obstacle generation, and spatial audio.
- Stack: Three.js, WebGL, TypeScript, Vite, Web Audio API.
- Outcome: Stable 60 FPS on low-power devices with a sub-2.5MB initial bundle load.
- Live Deployed: https://absolutely-sharad.github.io/The_Indian_Runner/
- GitHub Repository: https://github.com/absolutely-sharad/The_Indian_Runner
