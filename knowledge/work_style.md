# Sharad's Work Style & Engineering Principles

1. **Measurable Outcomes**: Engineering decisions must be tied to quantifiable business or user metrics (e.g. 30% latency reduction, 75% time saved).
2. **Deterministic Agent Loops**: When orchestrating LLMs, use strict JSON schemas, schema validation, and guardrails to prevent hallucinations.
3. **Hybrid RAG Strategy**: Always combine vector semantic similarity (dense retrieval) with BM25 keyword matching (sparse retrieval) to handle domain terms, acronyms, and proper nouns reliably.
4. **Velocity with Quality**: Demonstrated ability to deliver production MVPs in 2-4 weeks without sacrificing TypeScript strictness or API security.
